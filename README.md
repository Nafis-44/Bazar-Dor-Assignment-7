# Project name: BazarDor

# Short description
 Bazar dor is a web application for checking daily prices of essential products in Bangladesh and comparing prices across different markets.

## Technologies Used
- Next.js
- TypeScript
- React
- Tailwind CSS
- Toatifyer
- Better Auth
- MongoDB
- Daisy UI

## Key Features
1. View daily product prices.
2. Browse products by category.
3. Track price increases and decreases.
4. View product details and price history.
5. Compare prices across different markets.
